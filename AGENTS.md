# AGENTS.md

## Project Context
- **Domain:** Frontend music school website.
- **Goal:** Clean up the repository structure to improve organization.
- **Tech Stack:** HTML, CSS, JavaScript.

## Task Guidelines: Directory Restructuring
- **Format:** Move all image files (e.g., .png, .jpg) from the root directory into a newly created `images` folder.
- **Code Updates:** You are authorized to modify HTML, CSS, and JavaScript files **only** for the purpose of updating the file paths to point to the new `images` folder. 
- **Boundaries:** Do not alter the structural layout, design, or textual content of the website. Your only codebase modifications should be correcting image source paths.
