# Music School Website

## Project Description
A frontend music school website built to provide information about the school's classes, faculty, facilities, and more. This project serves as a comprehensive example of standard web development practices, focusing on a consistent, professional, and accessible user experience.

## Core Technologies
- **HTML:** For structuring the web pages.
- **CSS:** For styling and ensuring a consistent look and feel across the site.
- **JavaScript:** For adding interactivity to the pages.

## How to Run Locally
To run this project locally, simply double-click the `index.html` file to open it in any modern web browser. No complex server setup is required!

## Project Features
The website includes the following core features and structural requirements:

1. A main home page (`index.html`).
2. 6 additional pages covering various topics (classes, faculty, etc.).
3. Website design consistent with industry standards:
   - A clickable logo on the upper left of all pages that always redirects to the homepage.
   - A uniform color scheme implemented via CSS.
   - Consistent typography and overall look and feel across all pages using CSS.
   - Meaningful and structured content.
   - Proper use of multi-level headings.
   - A "Contact Us" page featuring a web form for user inquiries.
   - A global navigation menu on the left side or top of all pages.
4. An HTML table that includes:
   - No less than 20 cells.
   - A descriptive caption.
   - Cells spanning multiple rows and/or columns.
5. A comprehensive web form with no fewer than 20 elements, which must include:
   - Checkboxes.
   - Radio buttons.
   - Standard buttons.
   - Labels for inputs.
   - Submit and Reset buttons.
   - Text fields.
   - Date selection (validating for correct date format).
   - Range inputs.
6. Proper use of ordered or unordered lists.
7. Illustrative images (original photography or royalty-free), including at least one image that acts as a hyperlink.
8. Interactive pages that utilize JavaScript for dynamic behavior.
